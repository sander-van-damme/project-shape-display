# 02 — Design criteria

This stage translates the broad project description into constraints that engineering work can be tested against.

- [`design-target.md`](design-target.md) — product requirements and success criteria.
- [`fabrication-context.md`](fabrication-context.md) — available fabrication process, printer, material and qualification context.
- [`miniature-dimensions.md`](miniature-dimensions.md) — tabletop miniature scale and the basis for vertical-travel requirements.

These files define **what a solution must achieve and the environment it must work in**. The next stage asks which existing engineering disciplines, mechanisms and principles can help satisfy those criteria.
