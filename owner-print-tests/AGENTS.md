# Owner print-test handoff

This folder provides **optional, print-ready Bambu Studio `.3mf` projects for the Bambu Lab X1 Carbon with saved printer, filament and process settings and simple result forms** for Sander. There is no autonomous print queue. An assigned Codex engineer picks a test only within a clearly requested task; Sander may not print soon or ever, without blocking other work.

- Prefer **one small plate** answering one decision. At most three total **READY** jobs, prioritized P1/P2/P3; unused slots need not be filled.
- Follow `TEST-TEMPLATE.md` with `YYYY-MM-DD-<short-description>/test.md` and a **verified Bambu Studio `.3mf` project** in that same directory (not STL-only and not a geometry-only 3MF). Do not send Sander only OpenSCAD/Python or ask him to export CAD. State exact parts, label variants, slicer orientation/support/brim, material, estimated filament/time and a short, safe step-by-step test.
- Where relevant include **2–3 tolerance variants and several identical nominal samples** on a small plate. For long slender rods, check support stability through all layers, support removal and functional thread scarring; don't assert an unsupported upright part is qualified because a slicer printed no support path.
- Record printer conditions and actual fit, travel, friction, binding, damage, cleanup and other observations. An unperformed test is **unknown**, never a measured pass or failure; five coupons do not qualify thousands of parts.
- Track status DRAFT / READY / DEFERRED / COMPLETED / RETIRED. On new evidence, update genuine priority and retire stale print offers (preserve historic STLs as evidence) with a reason. No deadline, reminders, purchase or ever-growing backlog.


## Mandatory directory names and Bambu Studio projects

- Every test directory is prefixed **`YYYY-MM-DD-`** (date first introduced, not date of eventual printing or last modification), followed by a short kebab-case description, e.g. `2026-10-15-compact-screw-fit`. Names remain stable when results are added. Update all code includes, scripts and documentation references when relocating a directory.
- For every **new or reissued READY test**, the primary delivery is a **genuine Bambu Studio project `.3mf` for the Bambu Lab X1 Carbon** (normally the 0.4 mm nozzle). It must embed the printable parts, layout/orientation, selected printer/nozzle, filament, bed and **actual process settings**. Merely wrapping STL meshes in a 3MF file, or supplying an STL plus written recommendations, does not qualify. The STL/CAD sources may still be retained for engineering reproduction.
- Explicitly configure and document relevant **layer and first-layer heights, Arachne/Classic wall generator, line width and wall counts, infill, speeds, accelerations, supports and their placement, brim/raft, XY/hole/elephant-foot compensation, cooling and print order**. Thin threaded walls require particular care; never assume Bambu Studio defaults preserve them.
- **Reopen the saved 3MF in Bambu Studio, select/verify the X1 Carbon and slice it.** Inspect actual wall paths, thread continuity, open bores, bed adhesion and whether supports fill the threaded cavities. Log the Bambu Studio version, exact saved profile values, and slicer-estimated time/material (not physical observations). Don't claim READY if a usable configured 3MF and meaningful X1C slicer check could not be provided; clearly record the blocker instead.
- Owner results must distinguish saved recommended settings from **settings actually printed**. When settings are modified, record the changes or attach the printed 3MF. Older completed print packs with only STL remain valid historical evidence; do not fabricate a missing 3MF retroactively.
