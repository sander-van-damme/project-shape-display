## Primary and secondary holes.
Every cell in the grid contains a primary hole and optionally a secondary hole.
A cell with only a primary hole will only let air pass if its filter layer shifts to the correct position.
A cell with both a primary and secondary hole will always let air pass, irrespective of filter layer shifts.
