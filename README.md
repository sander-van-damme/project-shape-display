# RPG Shape Display

This file describes how to build a shape display for use in RPG games such as Dungeons and Dragons.

## Hardware

### Key components

- cuboids (1/4" x 1/4" x 2")
- cuboids bed
- cable driven actuator

### STL files

The STL files for the components are generated using SolidPython 2 and OpenSCAD.

## Software

- web controller
- 2D to 3D converter
